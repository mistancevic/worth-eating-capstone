# Worth Eating — capstone run

The XP meal-score idea taken through the full 4D path on synthetic data.

The point is the path, not the product. The real version lives in `worth-eating`
and is on hold until this is finished.

## Rules

1. One Companion question at a time. Nothing moves forward until that answer is
   settled.
2. Synthetic data only. No panel member, no real household, no real photograph.
3. Anything that belongs to the real app gets written to
   [`real-app-notes.md`](real-app-notes.md) and the conversation goes back to the
   question.
